# SIM800 Gateway: project site

Marketing / showcase site for this project (Next.js, App Router).

## Run locally
```bash
cd site
npm install
npm run dev
```

## Deploy on Vercel (works with private repos)
1. vercel.com → **Add New → Project** → import this repo
2. **Root Directory: `site`** (Framework is detected as Next.js)
3. Deploy. No environment variables needed.

The site is independent from the rest of the repo, so it never affects the main build.
