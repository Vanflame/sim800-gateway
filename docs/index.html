vanflame16-SIM ESP32 SMS gateway firmware
SIM800

● SIM800 Gateway

sixteen sims.
one tiny board.

ESP32 firmware that drives up to 16 SIM800L GSM modules through a CD74HC4067 multiplexer, polls every SIM for incoming SMS and forwards them to a backend, with a local web UI and over-the-air updates.

  • C++
  • ESP32
  • SIM800L
  • CD74HC4067
  • LittleFS
  • HTTPS OTA

01 / Features

what it actually does.

01

16-SIM polling

Shared TX and muxed RX let one UART serve sixteen modems.

02

Local web UI

Configure, monitor and manage SIMs from the device itself.

03

Dual Wi-Fi

Setup access point and backend connection at the same time.

04

HTTPS OTA

Firmware updates from GitHub Releases or a custom URL.

05

Missed-call OTPs

Converts missed-call verifications into OTP messages.

06

Self-healing

SIM watchdog, heartbeat sync and persistent error logs.
